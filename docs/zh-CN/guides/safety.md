# 安全与敏感数据

<a id="check"></a>

## 预测业务变化

全局 --check 不能被任务 check_mode:false 取消。它可暂存/清理临时 worker，但不能修改业务文件、账号、软件包、服务或启动 async。部分模块跳过而非预测，须看模块参考；语法/列表操作不连接目标。

<a id="identity"></a>

## 信任与身份

通过可信渠道核对 SSH 指纹，私钥不提交清单仓库，密码使用隐藏提示或密码来源。区分登录和提权身份；worker/请求/作业目录和文件保持私有，不能靠共享可读目录绕过身份隔离。安装/配置原生集合会以选定身份授权代码，并非沙箱；SHA256 证明完整性，不证明作者身份。

<a id="secrets"></a>

## Vault、no_log 与输出

Vault 保护存储中的配置；CLI view/decrypt、明确的 template/copy 部署仍会在指定位置输出明文。no_log 隐藏结果展示，不清空内存 register，也不意味着可以把秘密交给 debug 或第三方程序。凭据不进 argv，排查加密问题时不要直接打印变量；私有 async 结果在后续查询仍遮蔽。

<a id="failure"></a>

## 原子写入与结果不确定

内置内容安装在同文件系统暂存，保留未指定元数据后提交；摘要/校验/写入失败保留原内容，无不安全截断回退。任意 shell 命令仅拥有作者实现的保证。修改请求后失联时，先检查目标状态再决定下一步，uncertain 不是允许直接重放。
